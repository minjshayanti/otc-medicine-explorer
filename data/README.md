
# Project Datasets

This directory contains the original and standardized datasets used to construct the OTC Medicine Explorer.

## Files

- Original OTC medicine dataset: Source collection of 300 medicine products.
- OTC_Medicines_Standardized.csv: Cleaned dataset with standardized intended-use, intended-user, and dosage-form facets.

The final integrated dataset, OTC_Final_Classified_300.csv, is located in the repository root because it is used directly by the Streamlit application.

See the documentation directory for the data dictionary and taxonomy definitions.
