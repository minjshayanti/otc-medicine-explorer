
# Project Development Notebooks

These Google Colab notebooks document the development of the OTC Medicine Explorer.

## Execution Order

1. OTC Data Preparation
   - Data cleaning
   - Metadata validation
   - Facet standardization

2. OTC Facet Development
   - Invented facet development
   - Stratified sampling
   - Reference classification integration
   - Classification validation

3. OTC Automatic Classification
   - TF-IDF feature extraction
   - Multi-label logistic regression
   - Model evaluation and baseline comparison
   - Error analysis
   - Automatic classification of 100 medicines

4. OTC Faceted Browser
   - Streamlit application development
   - Faceted navigation
   - BM25 retrieval integration

## Reproducibility

The notebooks were developed using Google Colab.

Run the notebooks in numerical order and upload the required input datasets when prompted or before executing the relevant cells.

File paths may need to be adjusted depending on the execution environment.

The final application source code and integrated dataset are available in the repository root.
